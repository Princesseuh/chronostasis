# chronostasis-gui

Desktop app for the Chronostasis FFXIII modding suite, for players and modders.

- Player tab: apply fixes, tweak proxy settings, install and manage modpacks.
- Modder tab: browse game files, preview textures, audio, and text, and inspect models in a 3D viewer with the game's real shaders, skeletons, and animations.

Runs on Windows and Linux. Part of [Chronostasis](https://github.com/Princesseuh/chronostasis), a modding suite for the Final Fantasy XIII trilogy.
