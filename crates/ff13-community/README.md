# ff13-community

Support for the community mod-pack formats of the Final Fantasy XIII modding scene: the keyed `.bin` stream cipher used by the HD Project texture packs, the model edit-scripts used by the HD model packs (mesh subdivision, skeleton merge, part swaps), and the HD Fonts/GUI baker.

With it you can decode and install the existing HD packs on any platform, without the original Windows-only tooling.

Part of [Chronostasis](https://github.com/Princesseuh/chronostasis), a modding suite for the Final Fantasy XIII trilogy.
