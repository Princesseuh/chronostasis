# ff13-community

Support for community mod-pack formats used by the Final Fantasy XIII modding scene: the keyed `.bin` stream cipher used by HD Project texture packs, model edit-scripts (mesh subdivision, skeleton merge, and part swaps), and data-only modpack installation.

With it you can decode and install the existing HD packs on any platform, without the original Windows-only tooling.

Part of [Chronostasis](https://github.com/Princesseuh/chronostasis), a modding suite for the Final Fantasy XIII trilogy.
